# Luxury Hotel AI Concierge

A beginner-friendly Python project inspired by real hospitality chatbot and automation freelance briefs.

## What it demonstrates
- Keyword-based customer support
- Sample room-rate responses
- Hotel FAQ handling
- Booking inquiry collection prompt
- Human handoff messaging
- A simple interactive command-line interface

## Run it
1. Install Python 3.
2. Open this folder in VS Code.
3. Open the terminal in VS Code.
4. Run:

```bash
python hotel_concierge.py
```

If `python` doesn't work on Windows, try:

```bash
py hotel_concierge.py
```

## Try these messages
- `Hi`
- `What are your room prices?`
- `When is check-in?`
- `Is breakfast included?`
- `What's the Wi-Fi password?`
- `I'd like to book a room`
- `Can I speak to a human?`
- `quit`

## Important limitations
This is a portfolio demo with fictional hotel details and sample prices. It is **not** an actual AI model, live hotel system, booking engine, or WhatsApp integration. It cannot check room availability or create reservations. Replace sample data and add verification, privacy safeguards, testing, and approved integrations before any real deployment.
